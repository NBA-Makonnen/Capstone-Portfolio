# Capstone Portfolio

An interactive personal portfolio built to showcase front-end AI engineering work completed during my internship, alongside my AWS certifications.

## About

This isn't just a display case — the site itself is meant to be a working example of front-end AI engineering. Certifications (starting with AWS Cloud Practitioner) are shown as supporting credentials, but the core of the site is the projects built during this track.

## Features

- Interactive project showcase
- AI-generated project summaries (generated during development, baked into the site as static content — no live API calls, so no ongoing cost)
- AWS certifications on display

## Stack

- React + Vite
- TypeScript
- Tailwind CSS
- Deployed on Vercel

## Status

In active development as part of an 8-week AI Fluency / front-end AI engineering track.
